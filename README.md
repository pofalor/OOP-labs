# Объектно-ориентированное программирование

Лабораторные работы по ООП на C# (WinForms, .NET Framework). Сквозная тема всех работ — редактор геометрических фигур: круг, прямоугольник, треугольник, кольцо, эллипс, четырёхугольник.

## Содержание

| Работа | Тема |
|--------|------|
| laba_1 | Классы и инкапсуляция: независимые классы `Circle`, `Rectangle`, `Triangle` с приватными полями и методами рисования на `Bitmap` |
| laba_2 | Композиция и повторное использование: вынесение координат в класс `CustomPoint`, новая фигура `Ring` |
| laba_3 | Наследование и полиморфизм: абстрактный базовый класс `TFigure`, абстрактный метод `Draw()`, фигуры `Ellipse` и `Tetragon` |
| laba_4 | Виртуальные методы и перемещение фигур (`MoveTo`), перегрузка конструкторов |
| laba_5 | Управление видимостью фигур (`SetVisible`), доработка иерархии |
| laba_6 | Собственные коллекции: `CustomArray`, `CustomList`, контейнеры `BaseContainer` / `ArrayContainer` / `FigureContainer`, обёртка `FigureWrapper`, сохранение и загрузка фигур |

## Как запускать

Открыть решение нужной работы (`laba_N/laba_N.sln`, для laba_6 — `laba_6/laba_6/laba_6.sln`) в Visual Studio и запустить. Требуется .NET Framework и поддержка Windows Forms.

Для `laba_6` пакеты NuGet (`NPOI`, `MathNet.Numerics`, `SixLabors.ImageSharp` и др.) лежат в папке `packages` и подключены через `packages.config`.
